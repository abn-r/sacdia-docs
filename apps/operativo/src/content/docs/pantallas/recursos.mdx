Buscar y abrir documentos, imágenes, audios o videos publicados para tu alcance.

## Resultado esperado

Al terminar este recorrido, podrás buscar y abrir documentos, imágenes, audios o videos publicados para tu alcance.

## Quién puede utilizarlo

Usuarios incluidos por el nivel de visibilidad del recurso.

## Pantallas incluidas

- Lista de recursos
- Detalle y apertura

## Antes de comenzar

- Inicia sesión y confirma el club o sección activos.
- Mantén conexión estable para acciones que guardan o envían información.
- Si una acción no aparece, revisa primero el cargo y el contexto.

## Tareas principales

- Buscar por texto.
- Filtrar por tipo de recurso.
- Abrir imagen, PDF, audio o video.
- Descargar usando la URL temporal cuando esté disponible.

## Flujo recomendado

1. Abre **Recursos** y usa la búsqueda o filtro.
2. Selecciona un elemento para abrir su detalle.
3. Pulsa **Descargar**, **Ver imagen**, **Ver PDF** o **Ver video**.
4. Si el enlace expiró, vuelve al detalle para solicitar uno nuevo.

## Cómo verificarlo

El recurso se abre con el tipo correcto; las URLs firmadas no deben reutilizarse indefinidamente.

## Errores frecuentes

| Problema | Qué hacer |
|---|---|
| No aparece la acción | Tu cargo o contexto no incluye el permiso. Confirma la sección o solicita revisión de acceso; no intentes otra cuenta. |
| La pantalla no carga | Comprueba la conexión y usa **Reintentar**. Si continúa, conserva el mensaje y repórtalo desde Ayuda. |
| El estado no cambia | Actualiza la pantalla antes de repetir. No envíes una operación por segunda vez sin confirmar el resultado. |
| Aparece otro club o sección | Vuelve al tablero y cambia o confirma el contexto activo antes de guardar información. |
