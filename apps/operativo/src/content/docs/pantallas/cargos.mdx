Esta pantalla está registrada en la aplicación, pero no es una consulta operativa de cargos para usuarios.

## Resultado esperado

Identificar que la ruta no puede usarse para consultar o administrar cargos y continuar por el proceso directo cuando corresponda.

## Acceso

La ruta runtime registrada es `/role-assignments`; puede alcanzarse mediante navegación interna o **deep-link**. No tiene entrada visible. No se muestra como una opción utilizable desde Perfil.

## Estado operativo

`role_assignments` no está operativo como pantalla de cargos. Consume el endpoint de solicitudes globales `GET /requests/assignments`, no un recurso de cargos propios ni de asignaciones efectivas del usuario. Además, su modelo intenta interpretar un UUID como int, por lo que la respuesta no cumple el contrato que espera la vista.

No hay Mis cargos que consultar en esta ruta: No promete Mis cargos ni cargos efectivos. Tampoco debe usarse para interpretar altas, revocaciones ni el estado real de una asignación.

## Límites

- La existencia de una ruta o de un deep-link no equivale a una entrada visible ni a una pantalla disponible para la operación diaria.
- No se deben inferir cargos efectivos a partir de solicitudes globales.
- No se deben usar los estados de esta vista como estado de dominio del cargo. En backend, una asignación efectiva usa `active` y, al revocarse, queda `ended`.

## Alternativa funcional

Las personas responsables autorizadas pueden realizar la asignación directa siguiendo el proceso [Asignación de cargo en club o sección](/procesos/asignacion-cargo-club/). Ese flujo define permisos, alcance y validaciones del cargo.

## Cómo verificarlo

Verifica que Perfil no incluya una entrada para esta pantalla. Si se abre por un deep-link, no la tomes como evidencia de cargos vigentes ni como base para una decisión operativa.

## Si algo falla

- **Se necesita crear o cambiar un cargo:** no intentes resolverlo desde esta ruta; usa el proceso directo o solicita apoyo a una persona responsable autorizada.
- **La ruta muestra un error o información inconsistente:** conserva el mensaje y repórtalo como incompatibilidad entre la vista y el contrato de solicitudes; no repitas acciones ni extraigas conclusiones sobre cargos.
