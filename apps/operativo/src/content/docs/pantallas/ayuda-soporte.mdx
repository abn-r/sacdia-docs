Consultar preguntas frecuentes, contactar al equipo o reportar un problema con contexto técnico.

## Resultado esperado

Al terminar este recorrido, podrás consultar preguntas frecuentes, contactar al equipo o reportar un problema con contexto técnico.

## Quién puede utilizarlo

Todos los usuarios de la aplicación.

## Pantallas incluidas

- Centro de ayuda
- Preguntas frecuentes
- Contacto
- Reportar problema

## Antes de comenzar

- Inicia sesión y confirma el club o sección activos.
- Mantén conexión estable para acciones que guardan o envían información.
- Si una acción no aparece, revisa primero el cargo y el contexto.

## Tareas principales

- Buscar una respuesta frecuente.
- Enviar un correo de contacto.
- Reportar un problema incluyendo ruta y datos del dispositivo.
- Confirmar que el reporte fue enviado.

## Flujo recomendado

1. Abre **Ajustes > Ayuda y soporte**.
2. Busca primero en preguntas frecuentes.
3. Si el problema continúa, abre **Reportar un problema**.
4. Describe qué intentabas hacer y qué ocurrió; envía el reporte.
5. Usa **Contacto** para consultas que no sean fallas técnicas.

## Cómo verificarlo

La app confirma el envío o abre el cliente de correo; si falla, conserva la descripción para reintentar.

## Errores frecuentes

| Problema | Qué hacer |
|---|---|
| No aparece la acción | Tu cargo o contexto no incluye el permiso. Confirma la sección o solicita revisión de acceso; no intentes otra cuenta. |
| La pantalla no carga | Comprueba la conexión y usa **Reintentar**. Si continúa, conserva el mensaje y repórtalo desde Ayuda. |
| El estado no cambia | Actualiza la pantalla antes de repetir. No envíes una operación por segunda vez sin confirmar el resultado. |
| Aparece otro club o sección | Vuelve al tablero y cambia o confirma el contexto activo antes de guardar información. |
