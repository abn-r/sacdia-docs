Consultar el avance hacia las maestrías configuradas a partir de especialidades aprobadas.

## Resultado esperado

Al terminar este recorrido, podrás consultar el avance hacia las maestrías configuradas a partir de especialidades aprobadas.

## Quién puede utilizarlo

Usuarios autenticados con historial de especialidades.

## Pantallas incluidas

- Maestrías y hoja de ruta

## Antes de comenzar

- Inicia sesión y confirma el club o sección activos.
- Mantén conexión estable para acciones que guardan o envían información.
- Si una acción no aparece, revisa primero el cargo y el contexto.

## Tareas principales

- Consultar maestrías disponibles.
- Revisar especialidades requeridas y completadas.
- Identificar el siguiente requisito.

## Flujo recomendado

1. Abre **Maestrías** desde Formación.
2. Selecciona una maestría disponible.
3. Revisa el progreso calculado con tus especialidades aprobadas.
4. Abre la especialidad pendiente para continuar.

## Cómo verificarlo

La hoja de ruta separa requisitos completados y faltantes; una maestría sin configuración muestra un estado vacío, no progreso inventado.

## Errores frecuentes

| Problema | Qué hacer |
|---|---|
| No aparece la acción | Tu cargo o contexto no incluye el permiso. Confirma la sección o solicita revisión de acceso; no intentes otra cuenta. |
| La pantalla no carga | Comprueba la conexión y usa **Reintentar**. Si continúa, conserva el mensaje y repórtalo desde Ayuda. |
| El estado no cambia | Actualiza la pantalla antes de repetir. No envíes una operación por segunda vez sin confirmar el resultado. |
| Aparece otro club o sección | Vuelve al tablero y cambia o confirma el contexto activo antes de guardar información. |
