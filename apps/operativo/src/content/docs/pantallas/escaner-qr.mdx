Registrar asistencia o consultar un código válido usando la cámara.

## Resultado esperado

Al terminar este recorrido, podrás registrar asistencia o consultar un código válido usando la cámara.

## Quién puede utilizarlo

Usuarios con permiso de asistencia cuando se utiliza el modo de registro.

## Pantallas incluidas

- Escáner
- Resultado del escaneo

## Antes de comenzar

- Inicia sesión y confirma el club o sección activos.
- Mantén conexión estable para acciones que guardan o envían información.
- Si una acción no aparece, revisa primero el cargo y el contexto.

## Tareas principales

- Alternar cámara o linterna.
- Escanear asistencia de una actividad.
- Distinguir registro nuevo de una persona ya presente.
- Escanear otro código después del resultado.

## Flujo recomendado

1. Abre el escáner desde la actividad o acceso correspondiente.
2. Concede permiso de cámara si el sistema lo solicita.
3. Centra el código dentro del marco sin mover el dispositivo.
4. Revisa el resultado antes de escanear otra persona.

## Cómo verificarlo

La app informa si la asistencia se registró o si ya existía, sin crear duplicados.

## Errores frecuentes

| Problema | Qué hacer |
|---|---|
| No aparece la acción | Tu cargo o contexto no incluye el permiso. Confirma la sección o solicita revisión de acceso; no intentes otra cuenta. |
| La pantalla no carga | Comprueba la conexión y usa **Reintentar**. Si continúa, conserva el mensaje y repórtalo desde Ayuda. |
| El estado no cambia | Actualiza la pantalla antes de repetir. No envíes una operación por segunda vez sin confirmar el resultado. |
| Aparece otro club o sección | Vuelve al tablero y cambia o confirma el contexto activo antes de guardar información. |
