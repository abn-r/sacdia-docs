Enviar un comprobante para reconocer clases o especialidades y corregir los datos detectados.

## Resultado esperado

Al terminar este recorrido, podrás enviar un comprobante para reconocer clases o especialidades y corregir los datos detectados.

## Quién puede utilizarlo

Miembros autenticados; la revisión final corresponde al personal autorizado del campo local.

## Pantallas incluidas

- Carga de comprobante
- Procesamiento
- Revisión de elementos
- Estado del envío
- Editor de elemento

## Antes de comenzar

- Inicia sesión y confirma el club o sección activos.
- Mantén conexión estable para acciones que guardan o envían información.
- Si una acción no aparece, revisa primero el cargo y el contexto.

## Tareas principales

- Subir una imagen o PDF admitido.
- Esperar el procesamiento OCR.
- Revisar y corregir tipo, nombre o fecha detectados.
- Enviar el lote y atender correcciones posteriores.

## Flujo recomendado

1. Abre **Carga por certificado** y selecciona el archivo.
2. Confirma el envío y espera a que termine el procesamiento.
3. Revisa cada elemento detectado antes de enviarlo.
4. Corrige los elementos marcados y vuelve a enviar cuando sea necesario.
5. Consulta **Estado del envío** hasta obtener la resolución.

## Cómo verificarlo

El lote muestra cantidades de aprobados, rechazados y pendientes, sin elementos obligatorios sin revisar.

## Errores frecuentes

| Problema | Qué hacer |
|---|---|
| No aparece la acción | Tu cargo o contexto no incluye el permiso. Confirma la sección o solicita revisión de acceso; no intentes otra cuenta. |
| La pantalla no carga | Comprueba la conexión y usa **Reintentar**. Si continúa, conserva el mensaje y repórtalo desde Ayuda. |
| El estado no cambia | Actualiza la pantalla antes de repetir. No envíes una operación por segunda vez sin confirmar el resultado. |
| Aparece otro club o sección | Vuelve al tablero y cambia o confirma el contexto activo antes de guardar información. |
