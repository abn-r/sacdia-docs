Consultar el resumen personal y navegar a las tareas principales.

## Resultado esperado

Al terminar este recorrido, podrás consultar el resumen personal y navegar a las tareas principales.

## Quién puede utilizarlo

Usuarios autenticados.

## Pantallas incluidas

- Inicio
- Resumen de honores
- Próximas actividades

## Antes de comenzar

- Inicia sesión y confirma el club o sección activos.
- Mantén conexión estable para acciones que guardan o envían información.
- Si una acción no aparece, revisa primero el cargo y el contexto.

## Tareas principales

- Consultar el saludo y datos resumidos.
- Abrir próximas actividades.
- Revisar honores completados.
- Cerrar sesión de forma segura.

## Flujo recomendado

1. Abre la pestaña **Inicio**.
2. Revisa próximas actividades y avisos visibles.
3. Toca una tarjeta para continuar en el módulo correspondiente.
4. Para cerrar sesión, usa la acción del perfil y confirma.

## Cómo verificarlo

Las tarjetas abren el módulo correcto y el cierre de sesión regresa a la pantalla de acceso.

## Errores frecuentes

| Problema | Qué hacer |
|---|---|
| No aparece la acción | Tu cargo o contexto no incluye el permiso. Confirma la sección o solicita revisión de acceso; no intentes otra cuenta. |
| La pantalla no carga | Comprueba la conexión y usa **Reintentar**. Si continúa, conserva el mensaje y repórtalo desde Ayuda. |
| El estado no cambia | Actualiza la pantalla antes de repetir. No envíes una operación por segunda vez sin confirmar el resultado. |
| Aparece otro club o sección | Vuelve al tablero y cambia o confirma el contexto activo antes de guardar información. |
