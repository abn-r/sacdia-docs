## Resultado esperado

La persona responsable publica o consulta contenido mediante el proceso correcto y no asume que una acción genera la otra.

## Participantes

- Personal autorizado para publicar o administrar recursos según su alcance.
- Personas destinatarias que consultan recursos visibles para su cuenta.
- Personal autorizado para emitir notificaciones mediante su proceso propio.

## Antes de comenzar

- Confirma el contenido, el alcance y el permiso necesarios para publicar el recurso.
- Distingue si necesitas publicar un recurso, emitir una notificación o realizar ambas acciones por separado.

## Regla principal

**Recursos y notificaciones son procesos independientes.**

**Publicar un recurso no envía una notificación.**

La publicación deja el recurso disponible solo para el alcance que corresponda. Si también necesitas avisar a alguien, usa el proceso de notificaciones autorizado y verifica ese resultado por separado.

## Flujo completo

1. Prepara el recurso y confirma que su contenido es final.
2. Publícalo con el alcance permitido para tu responsabilidad.
3. Comprueba que el recurso aparece para una cuenta incluida en ese alcance.
4. Si se requiere un aviso, solicita o ejecuta el proceso de notificación como una acción distinta.
5. La persona destinataria revisa la [recepción de notificaciones](/procesos/recepcion-notificaciones/) y el recurso desde su pantalla correspondiente.

## Cómo verificarlo

- El recurso se abre para una cuenta que tiene visibilidad.
- La ausencia de una alerta no invalida la publicación del recurso.
- Si se emitió una notificación por un proceso separado, se comprueba en la bandeja de la cuenta destinataria.

## Si algo falla

| Situación | Qué hacer |
|---|---|
| El recurso no aparece | Confirma alcance, cuenta y conexión; después actualiza la lista una vez. |
| Esperabas una notificación | Verifica si se ejecutó el proceso de notificación independiente. No repitas la publicación para forzar un aviso. |
| No puedes publicar | Revisa tu cargo, permisos y alcance. Solicita apoyo a una persona autorizada. |
