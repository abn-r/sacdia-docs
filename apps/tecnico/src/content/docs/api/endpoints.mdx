- 🔒 `GET /api/v1/users/{userId}/master-honors` — Obtener maestrías del usuario
- 🔒 `GET /api/v1/users/{userId}/master-honors/{masterHonorId}` — Obtener detalle de una maestría del usuario
- 🔒 `GET /api/v1/users/{userId}/master-honors/roadmap` — Obtener roadmap de maestrías del usuario

## validation

- 🔒 `GET /api/v1/validation/{entityType}/{entityId}/history` — Historial de validacion
- 🔒 `POST /api/v1/validation/{entityType}/{entityId}/review` — Aprobar o rechazar clase/honor
- 🔒 `GET /api/v1/validation/eligibility/{userId}` — Verificar elegibilidad para investidura
- 🔒 `GET /api/v1/validation/pending` `?section_id?&entity_type?` — Listar items pendientes de revision
- 🔒 `POST /api/v1/validation/submit` — Enviar clase/honor a revision

## year-end

- 🔒 `POST /api/v1/year-end/{yearId}/close` — Cerrar ano eclesiastico
- 🔒 `GET /api/v1/year-end/{yearId}/preview` — Vista previa del impacto de cierre de ano
