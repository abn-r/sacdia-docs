## Librerias y Herramientas

### UI Components & Styling

- **UI Library**: shadcn/ui (registry `new-york`) sobre Radix UI
- **Styling**: Tailwind CSS v4 (con `@theme` y variables CSS via design tokens)
- **Icons**: `lucide-react` (no usar otro pack)
- **Forms**: React Hook Form + Zod + Form primitive `aria-invalid` propio
- **Diseño**: Ver `sacdia-admin/DESIGN-SYSTEM.md` (paleta Ember naranja cobre, tipografia Geist sans)

### State Management

- **Global State**: Context API minimal + Zustand para casos puntuales
- **Server State**: **TanStack Query v5** (`@tanstack/react-query`) — fuente unica para data del backend
- **Form State**: React Hook Form

> **NO se usa SWR**. La migracion a TanStack Query se completó en 2026-04.

### Routing

- **Router**: Next.js App Router (built-in)
- **Edge middleware**: `src/proxy.ts` (rename de Next.js 16 — antes era `middleware.ts`) protege rutas via cookie `ACCESS_TOKEN_COOKIE` (httpOnly)
- **i18n**: `next-intl` v4 + 4 idiomas: `es` (default), `en`, `fr`, `pt-BR`

### Data Fetching

- **HTTP Wrapper**: `lib/api/apiRequest.ts` propio + TanStack Query
- **Pattern**: hooks `useQuery({ queryKey, queryFn })` y `useMutation` con `queryClient.invalidateQueries`
- **GraphQL**: NO se usa — REST API

### Testing

- **Unit/Integration**: **Vitest** (no Jest)
- **Component Testing**: React Testing Library
- **Mocks de red**: **MSW** (Mock Service Worker) — wrapper provee `QueryClientProvider`
- **E2E custom**: `scripts/e2e-smoke.mjs`
- **No usamos Playwright** (por ahora)

### Build Tools

- **Bundler**: Next.js 16 con Turbopack
- **Package Manager**: pnpm 10
- **Bundle analyzer**: `@next/bundle-analyzer`

## Convenciones del Admin

- **Server Components por defecto**; `'use client'` solo donde el patron lo justifique (forms, interactividad, hooks de cliente)
- **CRUD**:
  - Dialog solo si ≤4 campos planos sin relaciones / uploads / tabs
  - Pagina dedicada obligatoria si >4 campos O cualquier relacion / imagen / tabs (DS §6.1.1)
- **Delete**: AlertDialog con confirmacion explicita
- **Catalog CRUD**: usar `CatalogCrudPage` (generico) o `PhaseECatalogCrudPage` (para los 22+ catalogos i18n-aware)
- **Tokens semanticos**: SIEMPRE `bg-primary/10`, `text-muted-foreground`, `text-destructive` — nunca hardcoded `bg-blue-50` o `text-red-500`
- **i18n**: usar `useTranslations()` de `next-intl`; los 24 catalogos translatable usan `TranslationsTabsField` + `<entity>_translations` overlay
- **Icons**: `lucide-react`, tamaños documentados en DS

## Notas para IA

- **Vitest + MSW** para tests (NO Jest, NO Playwright)
- next-intl 4 para i18n
- NO create-react-app, NO Vite standalone

**Patron TanStack Query**:

```typescript
// hooks/use-clubs.ts
export function useClubs() {
  return useQuery({
    queryKey: ['clubs'],
    queryFn: () => apiRequest<Club[]>('/clubs'),
  });
}

export function useCreateClub() {
  const qc = useQueryClient();
  return useMutation({
    mutationFn: (dto: CreateClubDto) => apiRequest('/clubs', { method: 'POST', body: dto }),
    onSuccess: () => qc.invalidateQueries({ queryKey: ['clubs'] }),
  });
}
```
