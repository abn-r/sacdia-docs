## Arquitectura

**Patron**: Clean Architecture (3 capas) + Riverpod para DI/state.

**Layout**:

```
lib/
├── core/                  # Utilidades, errores, network, realtime
│   ├── constants/
│   ├── errors/            # Failures (Either<Failure, T>)
│   ├── network/           # Dio client + interceptors
│   ├── realtime/          # RealtimeInvalidationHandler (FCM silent)
│   └── theme/             # Tema Material 3 + colores Ember
│
├── features/              # Bounded contexts
│   └── [feature]/
│       ├── data/          # data sources + models + repository impls
│       ├── domain/        # entities + repository contracts + usecases
│       └── presentation/  # pages + widgets + providers
│
└── shared/                # Widgets globales reutilizables
```

**Reglas**:
- `domain/` NO depende de Flutter ni de Dio.
- `domain/usecases/*` devuelven `Either<Failure, T>` (paquete `dartz`).
- `presentation/` consume via Riverpod providers — nunca data sources directos.
- Modelos (DTOs) en `data/models/`; entidades (puros) en `domain/entities/`.

## Autenticacion

**Provider**: Better Auth (self-hosted en backend).
**Token**: JWT **HS256** firmado por SACDIA con `BETTER_AUTH_SECRET`.
**Storage**: `flutter_secure_storage` ^9.2.4 (keychain en iOS, EncryptedSharedPreferences en Android).
**Refresh**: `POST /api/v1/auth/refresh` con body `{ refreshToken }`.
**OAuth**: Google + Apple via backend (`POST /auth/oauth/{provider}` → redirectUrl).

> **NO usar Supabase Flutter SDK**. Fue removido en Wave 3.

---

## State Management

**Riverpod**: `flutter_riverpod` ^2.6.1

- DI via providers (`Provider`, `FutureProvider`, `StreamProvider`, `StateNotifierProvider`)
- `autoDispose` para limpiar estado cuando una page se cierra
- `ref.invalidate(provider)` para invalidacion manual tras mutaciones
- Realtime cache invalidation: `RealtimeInvalidationHandler` recibe FCM silent push (`data.type == 'cache_invalidate'`) y llama `ref.invalidate(...)` segun el `resource` afectado

> **NO se usa `flutter_hooks`**, `bloc`, ni `provider` clasico.
