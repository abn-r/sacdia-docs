Administrar categorías y recursos visibles en la aplicación según su alcance.

## Resultado esperado

Al terminar este recorrido, podrás administrar categorías y recursos visibles en la aplicación según su alcance.

## Acceso requerido

- resources:read y permisos de gestión
- resource_categories:read/manage para categorías

El panel oculta opciones sin permiso efectivo. Ver una guía no concede acceso ni reemplaza la autorización del backend.

## Rutas incluidas

| Ruta | Uso |
|---|---|
| `/dashboard/resources` | Publicación de recursos. |
| `/dashboard/resources/categories` | Administración de categorías. |

## Antes de comenzar

- Confirma la cuenta, el alcance territorial y el periodo que vas a operar.
- Busca el registro antes de crearlo para evitar duplicados.
- Si no ves una acción, no intentes saltar el control mediante una URL directa.

## Tareas principales

- Crear y ordenar categorías.
- Crear un recurso de texto, imagen, audio, archivo o video.
- Definir alcance de visibilidad.
- Actualizar o desactivar.
- Comprobar la disponibilidad en la app.

## Flujo recomendado

1. Abre **Recursos** o **Categorías**.
2. Busca primero para evitar duplicados.
3. Completa tipo, categoría, contenido y alcance.
4. Guarda el recurso.
5. Confirma que aparece para un usuario incluido en el alcance.

## Cómo verificarlo

El recurso aparece solamente para divisiones, uniones, campos locales o tipos de club configurados.

## Errores frecuentes

| Problema | Qué hacer |
|---|---|
| No aparece la acción | Tu cargo o contexto no incluye el permiso. Confirma la sección o solicita revisión de acceso; no intentes otra cuenta. |
| La pantalla no carga | Comprueba la conexión y usa **Reintentar**. Si continúa, conserva el mensaje y repórtalo desde Ayuda. |
| El estado no cambia | Actualiza la pantalla antes de repetir. No envíes una operación por segunda vez sin confirmar el resultado. |
| El registro está fuera de alcance | Revisa el filtro territorial y la cuenta activa. El panel limita los datos al alcance autorizado. |
