Esta página orienta hacia el manual RBAC correcto. No sustituye los controles del backend ni replica los pasos de cada pantalla.

## Resultado esperado

Podrás identificar si tu tarea corresponde a roles, catálogo de permisos, matriz o una excepción directa por usuario.

## Acceso requerido

- **Roles:** consulta con `roles:read`.
- **Permisos:** consulta con `permissions:read`.
- **Cambios RBAC sensibles:** requieren rol exacto `super-admin` y `permissions:assign`.

El panel oculta opciones sin permiso efectivo. Ver una guía no concede acceso ni reemplaza la autorización del backend.

## Elegir el manual

| Necesidad | Manual |
|---|---|
| Crear, revisar, copiar, desactivar o sincronizar un rol | [Administración de roles](/configuracion/roles/) |
| Consultar o desactivar una clave técnica | [Catálogo de permisos](/configuracion/permisos/) |
| Revisar o sincronizar permisos de un rol | [Matriz de permisos](/configuracion/matriz-de-permisos/) |
| Gestionar una excepción global por persona | [Permisos directos por usuario](/configuracion/permisos-directos-usuario/) |

## Antes de comenzar

- Distingue el cargo organizacional, el permiso backend, el gate visual y el alcance: no son sinónimos.
- Confirma si el caso es un rol, una relación rol-permiso o una excepción directa.
- Si no ves una acción, no intentes saltar el control mediante una URL directa.

## Flujo recomendado

1. Identifica el tipo de cambio que necesitas realizar.
2. Abre el manual específico desde la tabla anterior.
3. Confirma los permisos y límites indicados para esa pantalla.
4. Ejecuta una sola operación y verifica su resultado en el mismo manual.

## Cómo verificarlo

Llegas al manual específico que describe el permiso, la ruta, la verificación y los límites de la tarea elegida.

## Límites actuales

- Esta guía no otorga acceso ni detalla las reglas operativas de cada pantalla.
- La visualización del menú no reemplaza la autorización efectiva del backend.

## Si algo falla

- **No sabes qué manual abrir:** identifica primero si cambias un rol, un permiso, una relación o una excepción por persona.
- **No aparece la acción:** consulta el manual específico y verifica el permiso backend y el rol exacto exigido antes de solicitar acceso.
