Acceder a configuración territorial, notificaciones, roles, permisos, variables y logros.

## Resultado esperado

Al terminar este recorrido, podrás acceder a configuración territorial, notificaciones, roles, permisos, variables y logros.

## Acceso requerido

- los permisos se evalúan por cada subsección

El panel oculta opciones sin permiso efectivo. Ver una guía no concede acceso ni reemplaza la autorización del backend.

## Antes de comenzar

- Confirma la cuenta, el alcance territorial y el periodo que vas a operar.
- Busca el registro antes de crearlo para evitar duplicados.
- Si no ves una acción, no intentes saltar el control mediante una URL directa.

## Tareas principales

- Abrir una familia de configuración.
- Configurar entrega y métodos de pago del campo local.
- Administrar notificaciones.
- Consultar o modificar RBAC.
- Mantener variables del sistema.

## Flujo recomendado

1. Abre **Configuración**.
2. Selecciona la tarjeta de la familia que deseas cambiar.
3. Comprueba el territorio y el permiso exigido.
4. Realiza el cambio y guarda.
5. Vuelve a la pantalla para confirmar que el valor persistió.

## Cómo verificarlo

La configuración aparece en la subsección correcta y no afecta otro territorio.

## Errores frecuentes

| Problema | Qué hacer |
|---|---|
| No aparece la acción | Tu cargo o contexto no incluye el permiso. Confirma la sección o solicita revisión de acceso; no intentes otra cuenta. |
| La pantalla no carga | Comprueba la conexión y usa **Reintentar**. Si continúa, conserva el mensaje y repórtalo desde Ayuda. |
| El estado no cambia | Actualiza la pantalla antes de repetir. No envíes una operación por segunda vez sin confirmar el resultado. |
| El registro está fuera de alcance | Revisa el filtro territorial y la cuenta activa. El panel limita los datos al alcance autorizado. |
