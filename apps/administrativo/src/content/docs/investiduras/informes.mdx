Consultar informes del club, abrir detalles, imprimir y supervisar el cumplimiento territorial.

## Resultado esperado

Al terminar este recorrido, podrás consultar informes del club, abrir detalles, imprimir y supervisar el cumplimiento territorial.

## Acceso requerido

- reports:read
- reports:supervise para supervisión territorial

El panel oculta opciones sin permiso efectivo. Ver una guía no concede acceso ni reemplaza la autorización del backend.

## Rutas incluidas

| Ruta | Uso |
|---|---|
| `/dashboard/reports` | Informes mensuales. |
| `/dashboard/reports/[reportId]` | Detalle del registro seleccionado. |
| `/dashboard/reports/supervision` | Pantalla operativa del módulo. |
| `/reports/monthly-preview` | Vista imprimible de un informe mensual. |

## Antes de comenzar

- Confirma la cuenta, el alcance territorial y el periodo que vas a operar.
- Busca el registro antes de crearlo para evitar duplicados.
- Si no ves una acción, no intentes saltar el control mediante una URL directa.

## Tareas principales

- Listar informes del enrollment activo.
- Abrir un informe y consultar sus secciones.
- Generar vista de impresión.
- Filtrar supervisión por territorio, tipo y periodo.
- Detectar informes faltantes.

## Flujo recomendado

1. Abre **Reportes**.
2. Selecciona lista propia o supervisión territorial.
3. Elige periodo y filtros.
4. Abre el informe y revisa datos automáticos y manuales.
5. Usa la vista de impresión cuando necesites el documento.

## Cómo verificarlo

El detalle y la vista imprimible pertenecen al mismo informe, club y periodo.

## Errores frecuentes

| Problema | Qué hacer |
|---|---|
| No aparece la acción | Tu cargo o contexto no incluye el permiso. Confirma la sección o solicita revisión de acceso; no intentes otra cuenta. |
| La pantalla no carga | Comprueba la conexión y usa **Reintentar**. Si continúa, conserva el mensaje y repórtalo desde Ayuda. |
| El estado no cambia | Actualiza la pantalla antes de repetir. No envíes una operación por segunda vez sin confirmar el resultado. |
| El registro está fuera de alcance | Revisa el filtro territorial y la cuenta activa. El panel limita los datos al alcance autorizado. |
