Revisar lotes OCR enviados por miembros y resolver cada elemento detectado.

## Resultado esperado

Al terminar este recorrido, podrás revisar lotes OCR enviados por miembros y resolver cada elemento detectado.

## Acceso requerido

- validation:read
- investiture:read

El panel oculta opciones sin permiso efectivo. Ver una guía no concede acceso ni reemplaza la autorización del backend.

## Rutas incluidas

| Ruta | Uso |
|---|---|
| `/dashboard/certificate-bulk-imports` | Pantalla operativa del módulo. |
| `/dashboard/certificate-bulk-imports/[batchId]` | Detalle contextual del elemento seleccionado. |

## Antes de comenzar

- Confirma la cuenta, el alcance territorial y el periodo que vas a operar.
- Busca el registro antes de crearlo para evitar duplicados.
- Si no ves una acción, no intentes saltar el control mediante una URL directa.

## Tareas principales

- Consultar lotes pendientes.
- Abrir el detalle del lote.
- Revisar comprobante y elementos detectados.
- Aprobar, rechazar o solicitar corrección.
- Confirmar el resumen del lote.

## Flujo recomendado

1. Abre **Validaciones > Cargas certificados**.
2. Selecciona un lote pendiente.
3. Contrasta el archivo con cada clase o especialidad detectada.
4. Registra la decisión y observación de cada elemento.
5. Confirma que el resumen no deje elementos sin resolver.

## Cómo verificarlo

El lote refleja aprobados, rechazados y pendientes, y el miembro puede consultar o corregir la resolución.

## Errores frecuentes

| Problema | Qué hacer |
|---|---|
| No aparece la acción | Tu cargo o contexto no incluye el permiso. Confirma la sección o solicita revisión de acceso; no intentes otra cuenta. |
| La pantalla no carga | Comprueba la conexión y usa **Reintentar**. Si continúa, conserva el mensaje y repórtalo desde Ayuda. |
| El estado no cambia | Actualiza la pantalla antes de repetir. No envíes una operación por segunda vez sin confirmar el resultado. |
| El registro está fuera de alcance | Revisa el filtro territorial y la cuenta activa. El panel limita los datos al alcance autorizado. |
