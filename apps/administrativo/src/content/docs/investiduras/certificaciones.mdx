Usa **Certificaciones de Guías Mayores** para consultar el avance de las
inscripciones y resolver las bandejas de requisitos y cierres.

## Resultado esperado

Podrás abrir el expediente correcto, revisar su evidencia dentro del alcance
autorizado y ejecutar únicamente la transición que corresponde a su estado.

## Acceso requerido

- `user_certifications:read`: consultar catálogo, inscritos y progreso.
- `certifications:review`: abrir bandejas y aprobar o solicitar cambios.
- `certifications:certify`: ejecutar la certificación final después de aprobar
  el cierre.

Configurar o publicar versiones usa permisos distintos y se documenta en
**Catálogos**. Ver una guía no concede acceso ni reemplaza la autorización del
backend.

## Rutas incluidas

| Ruta | Uso |
|---|---|
| `/dashboard/certifications` | Catálogo operativo y acceso a inscripciones. |
| `/dashboard/certifications/[id]` | Estructura, inscritos y progreso de una certificación. |
| `/dashboard/certifications/reviews` | Bandejas institucionales de requisitos y cierres. |

## Antes de comenzar

- Confirma la cuenta y el campo local con el que vas a revisar.
- Busca por certificación, participante y estado antes de tomar una decisión.
- Comprueba que no estás revisando tu propio expediente.
- No uses una URL directa para intentar ampliar el alcance.

## Elegir la bandeja correcta

La página de revisiones separa dos decisiones que NO son intercambiables:

| Bandeja | Qué recibes | Resultado posible |
|---|---|---|
| **Requisitos** | Un requisito enviado con respuestas, componentes y evidencias. | Aprobar o solicitar cambios sobre ese requisito. |
| **Cierres** | El expediente con requisitos aprobados y comprobante de junta. | Aprobar el comprobante, solicitar cambios o certificar cuando corresponda. |

Si buscas una respuesta o archivo de un requisito, usa **Requisitos**. Si la
persona ya terminó el programa y presentó el comprobante, usa **Cierres**.

## Revisar un requisito

1. Abre **Revisiones > Requisitos**.
2. Mantén el filtro en enviados o selecciona el estado que necesitas consultar.
3. Abre el registro y confirma participante, certificación, módulo y requisito.
4. Revisa todas las respuestas y componentes obligatorios.
5. Pulsa **Ver** para solicitar el acceso temporal a cada evidencia.
6. Elige una sola resolución:
   - **Aprobar**, si el requisito está completo;
   - **Solicitar cambios**, indicando claramente qué debe corregirse.
7. Actualiza la bandeja y confirma el nuevo estado.

La URL de descarga de una evidencia se genera al abrirla y tiene duración
limitada. No copies el enlace a otro sistema ni lo uses como archivo permanente.

## Solicitar cambios útiles

El comentario es obligatorio al devolver un requisito o cierre. Escribe una
instrucción que la persona pueda ejecutar:

- identifica el componente incompleto;
- explica qué evidencia o respuesta falta;
- evita comentarios genéricos como “corregir”;
- no solicites datos personales que el requisito no exige.

La persona debe corregir el mismo requisito. No le pidas crear otra inscripción.

## Resolver el cierre final

1. Abre **Revisiones > Cierres**.
2. Selecciona un expediente enviado para revisión final.
3. Confirma que los requisitos obligatorios estén aprobados.
4. Abre el comprobante de junta y valida que corresponda al expediente.
5. Elige:
   - **Aprobar comprobante**, si cumple;
   - **Solicitar cambios**, si necesita corrección.
6. Cuando el expediente esté `APPROVED`, pulsa **Certificar** solo si tienes
   `certifications:certify`.
7. Confirma la operación y actualiza la fila.

**Aprobar comprobante** y **Certificar** son etapas diferentes. No certifiques un
expediente que todavía esté enviado para revisión o con cambios solicitados.

## Cómo verificarlo

- El registro desaparece del filtro de enviados o muestra el nuevo estado.
- La decisión queda asociada al requisito o cierre que abriste.
- **Certificar** solo aparece con el permiso correcto y sobre filas aprobadas.
- El expediente final cambia a certificado, no únicamente a aprobado.

## Errores frecuentes

| Problema | Qué hacer |
|---|---|
| No aparece la bandeja | Confirma `certifications:review` y el alcance territorial efectivo. |
| La evidencia ya no abre | Regresa al detalle y pulsa **Ver** para solicitar una URL nueva. |
| Solicita un comentario | Describe la corrección concreta; no envíes una devolución vacía. |
| El registro cambió mientras lo revisabas | Actualiza el detalle y vuelve a evaluar el estado; no repitas la decisión anterior. |
| No aparece **Certificar** | El cierre debe estar aprobado y tu cuenta necesita `certifications:certify`. |
| El expediente está fuera de alcance | No cambies la URL ni la cuenta para saltar el control; solicita la asignación correcta. |
