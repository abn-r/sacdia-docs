Revisar solicitudes, seguir el pipeline y configurar responsables por campo local.

## Resultado esperado

Al terminar este recorrido, podrás revisar solicitudes, seguir el pipeline y configurar responsables por campo local.

## Acceso requerido

- investiture:read
- investiture:validate para resolver

El panel oculta opciones sin permiso efectivo. Ver una guía no concede acceso ni reemplaza la autorización del backend.

## Rutas incluidas

| Ruta | Uso |
|---|---|
| `/dashboard/investiture` | Pantalla operativa del módulo. |
| `/dashboard/investiture/config` | Configuración del módulo. |
| `/dashboard/investiture/pipeline` | Seguimiento por etapas. |

## Antes de comenzar

- Confirma la cuenta, el alcance territorial y el periodo que vas a operar.
- Busca el registro antes de crearlo para evitar duplicados.
- Si no ves una acción, no intentes saltar el control mediante una URL directa.

## Tareas principales

- Filtrar solicitudes pendientes.
- Revisar elegibilidad, evidencia e historial.
- Aprobar o rechazar con comentarios.
- Ejecutar operaciones masivas autorizadas.
- Consultar pipeline y configuración.

## Flujo recomendado

1. Abre **Investidura > Pendientes**.
2. Selecciona año y solicitud.
3. Revisa requisitos, historial y documentos.
4. Registra aprobación o rechazo con el comentario requerido.
5. Consulta **Seguimiento** para confirmar la etapa resultante.

## Cómo verificarlo

La solicitud sale de la cola correspondiente y el pipeline conserva actor, fecha y decisión.

## Errores frecuentes

| Problema | Qué hacer |
|---|---|
| No aparece la acción | Tu cargo o contexto no incluye el permiso. Confirma la sección o solicita revisión de acceso; no intentes otra cuenta. |
| La pantalla no carga | Comprueba la conexión y usa **Reintentar**. Si continúa, conserva el mensaje y repórtalo desde Ayuda. |
| El estado no cambia | Actualiza la pantalla antes de repetir. No envíes una operación por segunda vez sin confirmar el resultado. |
| El registro está fuera de alcance | Revisa el filtro territorial y la cuenta activa. El panel limita los datos al alcance autorizado. |
