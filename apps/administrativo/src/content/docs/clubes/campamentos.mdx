Gestionar camporees locales y de unión, agenda, eventos, jueces, pagos y clasificaciones.

## Resultado esperado

Al terminar este recorrido, podrás gestionar camporees locales y de unión, agenda, eventos, jueces, pagos y clasificaciones.

## Acceso requerido

- camporees:read
- camporees:update para cambios
- scoring_categories:read/manage para puntuación

El panel oculta opciones sin permiso efectivo. Ver una guía no concede acceso ni reemplaza la autorización del backend.

## Antes de comenzar

- Confirma la cuenta, el alcance territorial y el periodo que vas a operar.
- Busca el registro antes de crearlo para evitar duplicados.
- Si no ves una acción, no intentes saltar el control mediante una URL directa.

## Tareas principales

- Listar camporees locales o de unión.
- Abrir detalle, inscritos, agenda, pagos y clasificación.
- Crear o editar eventos y plantillas.
- Asignar jueces y consultar puntuaciones.
- Configurar el alcance territorial.

## Flujo recomendado

1. Abre **Campamentos** y elige el alcance local o unión.
2. Selecciona un camporee y revisa información e inscripciones.
3. Usa las pestañas para agenda, eventos, pagos, miembros o clasificación.
4. Realiza la acción autorizada y guarda.
5. Vuelve al detalle para confirmar el cambio.

## Cómo verificarlo

El cambio aparece en el camporee correcto y no modifica el alcance territorial equivocado.

## Errores frecuentes

| Problema | Qué hacer |
|---|---|
| No aparece la acción | Tu cargo o contexto no incluye el permiso. Confirma la sección o solicita revisión de acceso; no intentes otra cuenta. |
| La pantalla no carga | Comprueba la conexión y usa **Reintentar**. Si continúa, conserva el mensaje y repórtalo desde Ayuda. |
| El estado no cambia | Actualiza la pantalla antes de repetir. No envíes una operación por segunda vez sin confirmar el resultado. |
| El registro está fuera de alcance | Revisa el filtro territorial y la cuenta activa. El panel limita los datos al alcance autorizado. |
