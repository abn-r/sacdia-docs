Revisar solicitudes pendientes y aprobar o rechazar dentro del alcance administrativo.

## Resultado esperado

Al terminar este recorrido, podrás revisar solicitudes pendientes y aprobar o rechazar dentro del alcance administrativo.

## Acceso requerido

- requests:read o requests:review
- club_members:approve para membresía

El panel oculta opciones sin permiso efectivo. Ver una guía no concede acceso ni reemplaza la autorización del backend.

## Rutas incluidas

| Ruta | Uso |
|---|---|
| `/dashboard/requests/assignments` | Pantalla operativa del módulo. |
| `/dashboard/requests/membership` | Pantalla operativa del módulo. |
| `/dashboard/requests/transfers` | Pantalla operativa del módulo. |

## Antes de comenzar

- Confirma la cuenta, el alcance territorial y el periodo que vas a operar.
- Busca el registro antes de crearlo para evitar duplicados.
- Si no ves una acción, no intentes saltar el control mediante una URL directa.

## Tareas principales

- Cambiar entre membresía, asignaciones y traslados.
- Filtrar pendientes.
- Abrir datos de origen, destino y solicitante.
- Aprobar o rechazar con comentario.
- Confirmar la actualización del miembro.

## Flujo recomendado

1. Abre **Solicitudes** y elige el tipo.
2. Selecciona una solicitud pendiente.
3. Revisa persona, club/sección, motivo e historial.
4. Registra una decisión con observación cuando corresponda.
5. Actualiza la lista y confirma el nuevo estado.

## Cómo verificarlo

La solicitud deja la cola pendiente y el cambio de membresía, cargo o contexto se refleja sin duplicados.

## Errores frecuentes

| Problema | Qué hacer |
|---|---|
| No aparece la acción | Tu cargo o contexto no incluye el permiso. Confirma la sección o solicita revisión de acceso; no intentes otra cuenta. |
| La pantalla no carga | Comprueba la conexión y usa **Reintentar**. Si continúa, conserva el mensaje y repórtalo desde Ayuda. |
| El estado no cambia | Actualiza la pantalla antes de repetir. No envíes una operación por segunda vez sin confirmar el resultado. |
| El registro está fuera de alcance | Revisa el filtro territorial y la cuenta activa. El panel limita los datos al alcance autorizado. |
