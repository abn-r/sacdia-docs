SACDIA es una plataforma full-stack compuesta por tres aplicaciones principales que comparten convenciones, autenticacion y base de datos.

## Resumen del Stack

| Componente | Tecnologia | Lenguaje |
|---|---|---|
| Backend API | NestJS 11.x | TypeScript 6.x |
| Admin Web | Next.js 16 (App Router + proxy.ts) | TypeScript 5.x |
| App Movil | Flutter 3.27+ | Dart 3.6+ |
| Base de Datos | PostgreSQL 16 (Neon, 3 branches) | SQL |
| ORM | Prisma 7.x | - |
| Auth | Better Auth self-hosted (HS256 JWT) | - |
| Cache / Queue | Redis (BullMQ + cache-aside + throttler) | - |
| Storage | Cloudflare R2 (presigned URLs) | - |
| Observabilidad | Sentry + Firebase FCM | - |

## Metodologia

**Arquitectura**: Backend REST API + Multiples Clients (Web Admin + Flutter App)

**Metodologia de Desarrollo**: Clean Architecture aplicada en todas las capas

**Package Manager**: pnpm (backend y admin), pub (Flutter)
