## Pattern Recomendado: API Service Layer

Encapsular llamadas en una capa de servicio que exponga hooks reutilizables en Next.js (TanStack Query) y use cases en Flutter (Riverpod + Either).

---

## Next.js con TanStack Query v5

```typescript
// lib/api/services/clubs.service.ts
import { apiRequest } from '@/lib/api/apiRequest';

export interface Club {
  club_id: number;
  name: string;
  local_field_id: number;
  club_types: { club_type_id: number; name: string };
  active: boolean;
}

export const clubsApi = {
  list: () => apiRequest<Club[]>('/clubs'),
  detail: (id: number) => apiRequest<Club>(`/clubs/${id}`),
  create: (dto: Partial<Club>) => apiRequest<Club>('/clubs', { method: 'POST', body: dto }),
  update: (id: number, dto: Partial<Club>) =>
    apiRequest<Club>(`/clubs/${id}`, { method: 'PATCH', body: dto }),
  remove: (id: number) => apiRequest(`/clubs/${id}`, { method: 'DELETE' }),
};
```

```typescript
// hooks/use-clubs.ts
import { useQuery, useMutation, useQueryClient } from '@tanstack/react-query';
import { clubsApi } from '@/lib/api/services/clubs.service';

export function useClubs() {
  return useQuery({
    queryKey: ['clubs'],
    queryFn: clubsApi.list,
  });
}

export function useCreateClub() {
  const qc = useQueryClient();
  return useMutation({
    mutationFn: clubsApi.create,
    onSuccess: () => qc.invalidateQueries({ queryKey: ['clubs'] }),
  });
}
```

**Uso en componente** (Server Component que hace render inicial + Client Component que hidrata):

```tsx
// app/dashboard/clubs/page.tsx (Server Component)
import { ClubsList } from './_components/clubs-list';
import { clubsApi } from '@/lib/api/services/clubs.service';

export default async function ClubsPage() {
  const clubs = await clubsApi.list(); // SSR initial fetch
  return <ClubsList initialData={clubs} />;
}
```

```tsx
// _components/clubs-list.tsx (Client Component)
'use client';
import { useClubs } from '@/hooks/use-clubs';

export function ClubsList({ initialData }: { initialData: Club[] }) {
  const { data: clubs } = useClubs(); // hydrate from cache, refresca en background
  return <div>{(clubs ?? initialData).map(c => <div key={c.club_id}>{c.name}</div>)}</div>;
}
```

## Flutter con Dio + Riverpod + Either

```dart
// lib/features/clubs/data/datasources/clubs_remote_datasource.dart
class ClubsRemoteDataSource {
  final Dio dio;
  ClubsRemoteDataSource(this.dio);

  Future<List<ClubModel>> getClubs() async {
    final response = await dio.get('/clubs');
    final data = response.data['data'] as List;
    return data.map((json) => ClubModel.fromJson(json)).toList();
  }

  Future<ClubModel> createClub(ClubModel club) async {
    final response = await dio.post('/clubs', data: club.toJson());
    return ClubModel.fromJson(response.data['data']);
  }
}

// lib/features/clubs/domain/usecases/get_clubs.dart
class GetClubs {
  final ClubsRepository repository;
  GetClubs(this.repository);

  Future<Either<Failure, List<Club>>> call() => repository.getClubs();
}

// lib/features/clubs/presentation/providers/clubs_provider.dart
final clubsProvider = FutureProvider.autoDispose<List<Club>>((ref) async {
  final useCase = ref.read(getClubsUseCaseProvider);
  final result = await useCase();
  return result.fold(
    (failure) => throw Exception(failure.message),
    (clubs) => clubs,
  );
});
```

**Uso en widget**:

```dart
class ClubsPage extends ConsumerWidget {
  @override
  Widget build(BuildContext context, WidgetRef ref) {
    final clubsAsync = ref.watch(clubsProvider);

    return Scaffold(
      appBar: AppBar(title: const Text('Clubs')),
      body: clubsAsync.when(
        data: (clubs) => ClubsList(clubs: clubs),
        loading: () => const Center(child: CircularProgressIndicator()),
        error: (e, _) => Text('Error: $e'),
      ),
    );
  }
}
```

## Envelope de respuesta

Todas las respuestas usan envelope `{ status, data }` (admin) o `{ status: 'success', data }`.

```typescript
// apiRequest ya hace .json() y devuelve el body completo.
// Si tu endpoint envuelve en { data }, hacé:
const { data } = await apiRequest<{ data: Club }>('/clubs/1');
```

```dart
final response = await dio.get('/clubs/1');
final club = ClubModel.fromJson(response.data['data']);
```
