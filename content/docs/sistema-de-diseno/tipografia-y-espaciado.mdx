## 3. Tipografia

### 3.1 Fuentes

| Variable | Stack | Uso |
|----------|-------|-----|
| `--font-geist-sans` | `Geist Sans` (Google Fonts) + system fallbacks | **Todo el texto, incluyendo h1**. |
| `--font-geist-mono` | `Geist Mono`, `JetBrains Mono`, monospace | Codigo, valores tabulares |
| `--font-display` | apunta a `--font-geist-sans` | Reservado para futuro marketing. **Hoy NO usar en admin** — h1 usa Geist semibold. |

> **Nota**: Originalmente Ember introdujo `Instrument Serif` como `--font-display` para h1 de PageHeader. La regla activa (2026-05-11) revirtio eso: en el admin **todos** los titulos (incluyendo h1) usan **Geist sans** con `font-semibold tracking-tight`. Instrument Serif queda reservado para landing/marketing futuro, NO se usa en el admin.

### 3.2 Escala Tipografica

| Elemento | Clase | Tamano | Peso |
|----------|-------|--------|------|
| Titulo de pagina (h1 / PageHeader) | `text-2xl font-semibold tracking-tight` | 1.5rem | 600 |
| Subtitulo / Card Title | `text-base font-semibold` | 1rem | 600 |
| Nombre seccion sidebar | `text-[10px] font-semibold uppercase tracking-widest` | 10px | 600 |
| Texto normal | `text-sm` | 0.875rem | 400 |
| Texto auxiliar | `text-sm text-muted-foreground` | 0.875rem | 400 |
| Descripcion corta | `text-[13px] text-muted-foreground` | 13px | 400 |
| Label formulario | `text-sm font-medium` | 0.875rem | 500 |
| Label tipo tag | `text-xs font-medium uppercase tracking-wider` | 0.75rem | 500 |
| Valores numericos | `tabular-nums` | - | - |
| Table header | `text-xs font-medium uppercase tracking-wider text-muted-foreground` | 0.75rem | 500 |
| Badge | `text-xs font-medium` | 0.75rem | 500 |
| Micro texto | `text-[11px]` | 11px | - |
| Codigo inline | `rounded bg-muted px-1.5 py-0.5 text-xs font-mono` | 0.75rem | 400 |

### 3.3 Reglas tipograficas

- Nunca usar `font-size` arbitrario fuera de la escala
- Titulos: `font-semibold` (600) preferido sobre `font-bold` (700)
- Nunca usar `font-light` o `font-thin`
- Valores numericos: siempre `tabular-nums`
- Texto truncado: `truncate` con `max-w-*`

## 4. Espaciado y Layout

### 4.1 Radios de Borde (Ember)

| Token | Valor | Uso |
|-------|-------|-----|
| `--radius-xs` | `0.375rem` (6px) | Checkboxes, dots |
| `--radius-sm` | `0.5rem` (8px) | Badges pequenos |
| `--radius` | **`0.75rem` (12px)** | **Base Ember** (antes 8px) |
| `--radius-md` | `1rem` (16px) | Inputs, buttons |
| `--radius-lg` | `1.25rem` (20px) | Cards, dialogs |
| `--radius-xl` | `1.5rem` (24px) | Cards grandes, login |
| `--radius-2xl` | `2rem` (32px) | Elementos especiales |
| `--radius-3xl` | `2.5rem` (40px) | Hero / decorativo |

**Clases**:
- `rounded-md` -> Inputs, buttons (16px)
- `rounded-lg` -> Cards (20px)
- `rounded-xl` -> Modals, login (24px)
- `rounded-full` -> Avatars, dots, badges circulares

### 4.2 Grid del Dashboard

```
Layout principal:
  Sidebar (w-64, sticky top-0, h-screen) | Contenido (flex-1)

Contenido:
  Header (h-16, sticky top-0, border-b)
  Main (padding: p-4 md:p-6)

Spacing vertical entre secciones:
  space-y-6   -> Principal entre secciones de pagina
  space-y-5   -> Dentro de cards o secciones menores
  space-y-4   -> Formularios, listas
  space-y-3   -> Elementos compactos

Padding en Cards:
  p-5         -> CardContent estandar
  p-4         -> CardFooter, secciones compactas
  p-7         -> Formularios de login (especial)
```

### 4.3 Grids de Tarjetas

| Contexto | Clase |
|----------|-------|
| KPIs / Estadisticas (4 cols) | `grid grid-cols-1 gap-4 sm:grid-cols-2 xl:grid-cols-4` |
| Tarjetas de contenido (3 cols) | `grid grid-cols-1 gap-4 md:grid-cols-2 xl:grid-cols-3` |
| Metricas simples (3 cols) | `grid grid-cols-1 gap-3 sm:grid-cols-3` |
| Grafico + Sidebar | `grid grid-cols-1 gap-6 lg:grid-cols-3` con `col-span-2` en grafico |

### 4.4 Breakpoints

| Breakpoint | Pixel | Uso |
|------------|-------|-----|
| `sm` | 640px | Grids 2-col, responsive |
| `md` | 768px | Sidebar visible, tabla desktop |
| `lg` | 1024px | Grids de graficos |
| `xl` | 1280px | Grids 3-4 columnas |

### 4.5 Sombras (Ember)

Escala custom con `--shadow-xs` casi imperceptible para cards. Ver `globals.css` del admin para los tokens exactos.

### 4.6 Dark mode

`body::before` aplica una textura noise sutil para profundidad sin glassmorphism. Tokens semanticos cambian automaticamente con `[data-theme=dark]`.
